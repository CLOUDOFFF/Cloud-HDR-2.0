# ВАЖНО про PyTorch и RTX 5060.
#
# RTX 5060 — это архитектура Blackwell, вычислительная способность sm_120.
# Колёса torch с PyPI собраны под более старые CUDA и кода для sm_120 не
# содержат: карта определится, память покажется, а первый матмул упадёт с
# «CUDA error: no kernel image is available for execution on the device».
#
# Поэтому torch ставится ОТДЕЛЬНОЙ командой, из индекса сборок под CUDA 12.8:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#     pip install -r requirements.txt
#
# Проверить, что всё сошлось:  python -m cloudhdr_ai info
# (команда прямо скажет, поддерживает ли установленная сборка вашу карту).
#
# Без видеокарты всё работает и на процессоре — обучение просто идёт медленнее:
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
